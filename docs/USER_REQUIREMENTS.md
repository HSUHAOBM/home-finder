# 房源篩選規則

## 共通硬條件

- 行政區、總價上限與理想價格由使用者在本機設定。
- 本文件說明條件判讀方式，不記錄個人預算或議價底線。
- 資料不明不視為合格，改列「待人工確認」

## 方案一：大樓、公寓、華廈

可設定平面汽車位、主建物坪數與房數門檻，以及樓層、衛浴數與屋齡偏好；是否列為必要條件依目前設定判斷。

591 的「權狀坪數」包含公設與車位，不能代替室內空間。主建物坪數條件應以「主建物」欄位判斷。

## 方案二：透天、別墅

詳情的建物型態須確實是透天厝或別墅；汽車位需求、屋齡與花園／庭院偏好依目前設定判斷。

標題即使出現「車墅、透天、別墅」，若詳情型態是電梯大樓、華廈或公寓，仍會淘汰。

## 方案三：預售屋

可設定平面汽車位、主建物坪數、房數與衛浴數條件。

預售屋常只標示房屋總坪數或「室內含陽台」，若無法取得主建物拆分，會列為待確認而不是直接通過。

## 591 資料可信度

詳情頁結構化欄位優先於廣告標題與自由描述。例如標題寫「平車」，但詳情寫「車位：無」，會以無車位淘汰並留下矛盾警示。

同一物件可能由不同仲介重複刊登。工具以行政區、地址或社區、坪數、房數、樓層產生疑似重複群組；不同開價仍會被放在同一群，供人工比較。
