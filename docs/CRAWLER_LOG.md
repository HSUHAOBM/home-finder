# 591 爬蟲查證紀錄

每次自動搜尋與直接查核都會追加至 `data/crawler_591_trace.jsonl`，以 UTF-8 JSON Lines 保存，不覆寫前次紀錄。既有 `data/crawl_audit.jsonl` 仍記錄成功入庫結果。

每筆事件包含 UTC 時間、`run_id`、來源、搜尋目標與事件名稱。用 `run_id` 串起同一輪搜尋；臺灣時間為 UTC 加 8 小時。

記錄內容包括搜尋參數、實際列表網址、原始卡片數、每張卡片的文字與解析資料、解析失敗、行政區／價格／型態排除原因、重複房源、翻頁停止原因、分段查詢結果、空批次重試、詳情快取命中、詳情筆數上限、詳情解析結果與錯誤，以及整輪完成或失敗。

在專案目錄的 PowerShell 查某筆房源：

```powershell
Select-String -LiteralPath "data/crawler_591_trace.jsonl" -SimpleMatch "21032611"
```

取得該筆的 `run_id` 後，使用相同指令搜尋該 ID，可查看同輪搜尋範圍與翻頁紀錄。

若房源 ID 完全沒有出現，只能確認爬蟲沒有在已讀取卡片中記錄該 ID；不能據此證明 591 沒有刊登。需再檢查時間條件、搜尋網址、翻頁停止與列表逾時事件。

LOG 從新程序載入本次程式後開始生效，無法補回過去漏收時的原始卡片。這次加入紀錄，不改變既有篩選與翻頁行為。原始卡片可能包含仲介資訊；LOG 為本機查證資料，分享前請檢查內容。紀錄不自動刪除，請定期檢查檔案大小。
